
[[[ CWXEditor F9版 ]]]

[ これは何？ ]

　CWXEditorの開発途中版です。
　正式なリリースではなく、都度公開されるデイリービルドのようなものです。
つまるところその品質は大方リリースする水準には達していないので、一面の
地雷原のようなものと思って、覚悟の上で使用してください。


[ リリース版との大きな違い ]

・起動するとコンソールが表示されます。エラー発生時のメッセージや、
　終了する際のシステムメッセージなどが表示されます。
　コンソールを閉じるとCWXEditorも終了します。
・リリース版よりも多くの場面で"cwxeditor_error.log"にエラーログが
　書き出されます。


[ 何のためにあるの？ ]

　このバージョンを使う事で得られるメリットは二つくらいあります。

・リリース版には搭載されていない最新の機能を使えるかもしれない。
・バグを踏む事によって開発に貢献できるかもしれない。

　デメリットも二つくらいあります。

・コンソールが邪魔。
・バグなりいい加減な実装なりを踏んでトラブルが置きやすい。
　最悪データを失ってもおかしくない。

　要するに「最新の機能使わせてあげるから人柱になってよ」という事です。
